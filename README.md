# 划词预览 · SelectionPreview

Windows 托盘工具。选中文字后，在选区上方显示原文卡片，无需复制，也不会抢走当前窗口的焦点。这个工具可以单独运行，不依赖字幕历史。

## 使用

- 按住左或右 `Ctrl` 再划词，浮窗才会出现；松开 `Ctrl` 会立即收起。按住期间支持双击选词、拖选、`Shift` + 单击、`Ctrl+Shift` + 方向键等键盘扩选，以及 `Ctrl+A`。拖动结束或连续按键停顿后才弹出。若应用支持三击选中整行（如记事本），第三击松开后会用新的选区更新卡片。
- 卡片不会定时收起，松开 `Ctrl` 时立即隐藏。再次点击、滚动、切换窗口、按 `Esc` 或按其他非修饰键仍可收起。上方放不下时优先放到下方。长选区只显示开头。
- 右键托盘图标可暂停、恢复或退出。暂停会停止监听；不会设置开机自启。

工具只通过 Windows UI Automation 读取选区。能在某个应用中选中文字，不代表该应用会对外提供选区。不能读取、没有可靠显示位置、读取超时、处于安全桌面或访问权限不足时，不显示卡片。不会读写剪贴板、模拟按键、保存原文或联网；系统标记的密码控件会被跳过。安装可选词库后可离线查英文单词和中文词语、成语；暂不翻译句子、不建生词本。卡片是普通桌面窗口，可能出现在录屏或屏幕共享中。

## 离线中英双向词典

在项目目录运行 `./Setup-Dictionary.ps1` 安装尚未安装的词库；已装英汉词库时，只补装汉英词库。普通构建和程序运行不会下载任何词库。需要重新安装两份词库时使用 `-Force`，任一安装失败不覆盖该方向已有的词库。

| 方向 | 来源与许可 | 一次性下载 | 本地文件（`%LOCALAPPDATA%\SelectionPreview`） |
| --- | --- | --- | --- |
| 英汉 | [ECDICT](ECDICT-NOTICE.md)，脚本核对固定版本的 SHA-256 | 约 66 MB | `dictionary-v1.sqlite`，约 20 MiB |
| 汉英 | [CC-CEDICT](CC-CEDICT-NOTICE.md)，脚本验证官方数据格式并记录来源和 SHA-256 | 约 4 MB | `dictionary-zh-v1.sqlite`，约 10 MiB |

按住 `Ctrl` 选中 `week`、`电脑`、`電腦` 或 `画蛇添足`，卡片先显示原文，再在下方补上最多两条释义。常见外层标点不影响查询。中文支持 1–32 个连续汉字的精确匹配，不拆分句子；英文仍只查单词，不查短语。中英混排、网址、未收录的词和对应词库不可用时只显示原文。查词不联网、不上传选区、不保存查询记录。

## 构建和运行

使用 Windows 10/11 x64，构建需要 .NET 8 或兼容 SDK，运行需要 .NET 8 Windows Desktop Runtime。初次构建要从 NuGet 还原依赖；程序运行不需要网络。

```powershell
.\build.ps1
.\dist\SelectionPreview.exe
```

构建会运行手势、过期结果、计时、坐标、Unicode 截断和词典测试，并将程序发布到 `dist`。如需移动程序，请复制整个 `dist` 目录。

## 手动验证

1. 在记事本新建两行中英文样例，按住 `Ctrl` 测试拖选、双击选词、三击选行、`Shift` 扩选和 `Ctrl+A`；确认未触动原选区或剪贴板，且浮窗不会阻止鼠标操作。在同一行的行尾空白处分别双击和三击：双击没有可预览文字时不应弹窗，三击实际选中整行时应显示该行。再在 Edge 的普通网页正文和输入框测试。
2. 确认不按 `Ctrl` 划词不弹窗；按住 `Ctrl` 划词后保持不动至少 10 秒，卡片应一直显示，松键立即收起。再试普通单击、空选区、测试用密码框、滚动、切窗和暂停，确认原有行为不变。
3. 使用缩放比例不同的双屏，分别在上下边缘选字。确认工作区定位正确，浮窗不跨出目标屏幕。在 125%、150% 或 200% 缩放下，按住 `Ctrl` 选中 `week` 等短词应完整显示；长段落仍应在卡片尺寸上限内换行或截断。
4. 安装词库后，在断网环境下按住 `Ctrl` 选择 `week`、`WEEK.`、`电脑`、`電腦`、`「星期。」` 和 `画蛇添足`；确认快速切换中英文选区不会串词，松键或切窗后也不会再出现。试选未收录的中文句子、中英混排和 URL，应只显示原文。

托盘负责监听手势，后台分别读取选区和查词，当前查词结果只在内存中交给卡片。
