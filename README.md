# CtrlLookup：划词预览与离线查词

CtrlLookup 是一个 Windows 托盘工具。按住 `Ctrl` 选中文字，浮窗会显示原文；安装可选词库后，还能离线查英汉、汉英释义。配置 LLM 后，也可按住 `Alt` 检查拼写或润色。不用复制，也不会抢走当前窗口的焦点。

## 快速开始

在项目目录运行以下命令。构建需要 Windows 10/11 x64 和 .NET 8 或兼容 SDK，首次构建需要联网还原 NuGet 依赖。运行需要 .NET 8 Windows Desktop Runtime；只有下载可选词库时才需要网络。

```powershell
.\build.ps1
.\dist\CtrlLookup\CtrlLookup.exe
```

构建会先运行自动化测试，再发布应用。如需移动程序，请复制整个 `dist\CtrlLookup` 目录，不要只复制 `.exe`。从旧版 `SelectionPreview.exe` 升级时，请先从托盘退出旧版；已安装的词库可以直接使用。

## 划词预览

- 拖选或双击选词时按住左或右 `Ctrl`。拖选可以先按下鼠标，再在松开前按下 `Ctrl`。也支持 `Shift` + 单击扩选、`Ctrl+Shift` + 方向键扩选和 `Ctrl+A`。拖动结束或连续按键停顿后才显示预览；如果应用支持三击选行，第三击松开后会更新预览。
- 浮窗优先显示在选区上方，上方空间不足时优先放到下方。长选区只显示开头。
- 浮窗不会自动超时；松开本次使用的 `Ctrl` 或 `Alt` 就会收起。再次点击、滚动、切换窗口、按 `Esc` 或按其他非修饰键也可收起。
- 右键托盘图标可暂停、恢复或退出。暂停会停止监听。程序不会设置开机自启。

## 可选：离线词典

启动时，程序会检查英汉和汉英词库是否已安装。缺少任一词库时，选择「是」会打开 `Setup-Dictionary.cmd`，仅下载并安装缺少的词库；选择「否」仍可使用划词预览及已安装的词库。两个词库都已安装时不会提示。词库安装完成后无需重启。

也可以在程序目录双击 `Setup-Dictionary.cmd` 稍后安装。发布目录包含安装工具，无需额外安装 SDK；从源码目录运行脚本时需要 .NET SDK。需要重新安装时运行 `.\Setup-Dictionary.ps1 -Force`；某个方向安装失败不会覆盖该方向已有的词库。

| 方向 | 数据来源 | 一次性下载 | 本地数据库 |
| --- | --- | --- | --- |
| 英汉 | [ECDICT](ECDICT-NOTICE.md)，校验固定版本的 SHA-256 | 约 66 MB | `dictionary-v1.sqlite`，约 20 MiB |
| 汉英 | [CC-CEDICT](CC-CEDICT-NOTICE.md)，验证数据格式并记录来源和 SHA-256 | 约 4 MB | `dictionary-zh-v1.sqlite`，约 10 MiB |

词库存放在 `%LOCALAPPDATA%\SelectionPreview`，应用改名后目录不变。

试着按住 `Ctrl` 选中 `week`、`电脑`、`電腦` 或 `画蛇添足`。浮窗先显示原文，查到后在下方补上最多两条释义。常见外层标点不影响查词。英文只查单词（不区分大小写）；中文支持 1–32 个连续汉字的整词匹配，支持简体和繁体，不会自动分词。纯网址只显示原文。单个词若离线词库没有释义，以及由多个词或句子组成的选区，在配置了在线补译后会显示译文；未配置时只显示原文。

## 在线补译和写作助手

离线词库查不到单个英文单词或连续汉字时，以及选区包含多个词或句子时，可以把这段文字发给兼容 OpenAI Chat Completions 的接口。单词最多显示两行释义；短语和句子显示译文，并保留换行。纯网址不发送。未配置、请求被取消、超时或接口失败时，浮窗仍只显示原文。一次最多发送 1200 个字符。

在 `%LOCALAPPDATA%\CtrlLookup\llm.json` 写入：

```json
{
  "endpoint": "https://api.openai.com/v1/chat/completions",
  "model": "gpt-4o-mini",
  "apiKey": "your-key"
}
```

本地服务不需要密钥时可以省略 `apiKey`。环境变量 `CTRLLOOKUP_LLM_ENDPOINT`、`CTRLLOOKUP_LLM_MODEL` 和 `CTRLLOOKUP_LLM_API_KEY` 同时给出端点和模型时优先于该文件。修改配置后需要重新启动。成功的单词补译会记入查词记录，并在本次运行中复用。短语和句子不写入查词记录。DeepSeek 默认会先思考，补译请求会关闭思考，避免译文留在思考过程里。词库里已有的单个词不会再发给模型。

### 按住 Alt 检查拼写或润色

使用同一套 LLM 配置。按住左或右 `Alt`，拖选或双击文字，也可以开始拖选后在松开鼠标前按下 `Alt`。保持按住 `Alt` 等待结果。单个英文单词显示最多五条拼写建议；其他文字按原语言润色，不翻译。结果会替换浮窗中的预览文字，但不会修改原应用中的文字，也不会写入查词记录。未配置 LLM 或请求失败时只显示原文。同时按 `Ctrl` 和 `Alt` 不触发。

润色结果中，新加或改写的文字会以加粗和浅黄色底纹标出（Windows 高对比度模式下使用下划线），未改动的文字保持原样。删掉的文字不会显示，只有空白变化时不高亮。单词拼写建议不使用这种标记。

## 查词记录

程序会将查到释义的词追加到 `%LOCALAPPDATA%\CtrlLookup\lookup-history.txt`（UTF-8），一行一条，重复查词也会保留。英文查词记录小写单词；中文查词只记录查到的英文单词或短语，不保存中文原词。未安装对应词库或未查到释义时不会写入。夹带中文的释义也不会写入。可以随时删除该文件以清空记录。

## 兼容性与隐私

程序只通过 Windows UI Automation 读取选区。应用允许选中文字，不代表它也会通过 UI Automation 提供选区。选区无法读取、缺少可靠的定位信息、读取超时、处于安全桌面或权限不足时，不会弹窗。程序会跳过系统标记的密码控件，不读写剪贴板、不模拟按键。未配置 LLM 时不上传选区；配置后，`Ctrl` 选区仅在需要补译时发送，`Alt` 选区会发送给同一接口以获取拼写建议或润色。每次最多发送 1200 个字符，纯网址不上传。除上述本地查词记录外，不保存选区内容。浮窗是普通桌面窗口，可能出现在录屏或屏幕共享中。

## 手动验证

1. 在记事本和 Edge 网页正文或输入框中测试拖选、双击、键盘扩选和 `Ctrl+A`。原选区和剪贴板应保持不变；浮窗不应阻挡鼠标。在记事本的行尾空白处双击，没有选中文字时不应弹窗；三击实际选中整行时应显示该行。
2. 不按 `Ctrl` 或 `Alt` 划词不应弹窗。先按下鼠标拖选，在松开前按下 `Ctrl`，松手后应弹窗。按住 `Ctrl` 划词后保持至少 10 秒，浮窗应持续显示，松键立即收起。再测试普通单击、空选区、测试用密码框、滚动、切窗和托盘暂停。
3. 在缩放比例不同的双屏上测试上下边缘的选区，确认浮窗不会超出目标屏幕。在 125%、150% 或 200% 缩放下，`week` 等短词应完整显示，长段落应在浮窗尺寸上限内换行或截断。
4. 在未安装词库的新环境启动程序，确认可选择下载或跳过。仅安装一个词库时，应只提示并下载缺少的词库；两份均已安装时，启动不应提示。
5. 安装词库后断网，测试 `week`、`WEEK.`、`电脑`、`電腦`、`「星期。」` 和 `画蛇添足`。快速切换选区不应显示上一词的释义；松开 `Ctrl` 或切窗后，迟到的查词结果不应让浮窗重新出现。未收录的纯网址应只显示原文。配置 `llm.json` 后，未收录的单词、多个词和句子应显示在线译文；不配置时仍只显示原文。按住 `Ctrl` 直到译文出现。
6. 在新版 Outlook 邮件正文和撰写窗口中，按住 `Ctrl` 拖选或双击带格式的正文文字（尤其是嵌套列表中的单词）。浮窗应显示实际选中的文字；松开 `Ctrl` 时收起。
7. 配置 LLM 后，分别用左、右 `Alt` 选中 `recieve` 和 `Please reply me soon.`，确认浮窗分别显示拼写建议和润色结果。润色时应只突出新增或改写的部分（如 `to`），原文和查词记录不变。请求期间松开 `Alt`、切换窗口或改用 `Ctrl`，迟到的结果不应出现。同时按 `Ctrl` 和 `Alt` 划词不应触发。
