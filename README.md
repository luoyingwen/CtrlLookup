# CtrlLookup：划词预览与离线查词

CtrlLookup 是一个 Windows 托盘工具。按住 `Ctrl` 选中文字，浮窗会显示原文；安装可选词库后，还能离线查英汉、汉英释义。不用复制，也不会抢走当前窗口的焦点。

## 快速开始

在项目目录运行以下命令。构建需要 Windows 10/11 x64 和 .NET 8 或兼容 SDK，首次构建需要联网还原 NuGet 依赖。运行需要 .NET 8 Windows Desktop Runtime，不需要网络。

```powershell
.\build.ps1
.\dist\CtrlLookup\CtrlLookup.exe
```

构建会先运行自动化测试，再发布应用。如需移动程序，请复制整个 `dist\CtrlLookup` 目录，不要只复制 `.exe`。从旧版 `SelectionPreview.exe` 升级时，请先从托盘退出旧版；已安装的词库可以直接使用。

## 划词预览

- 按住左或右 `Ctrl`，然后拖选或双击选词。也支持 `Shift` + 单击扩选、`Ctrl+Shift` + 方向键扩选和 `Ctrl+A`。拖动结束或连续按键停顿后才显示预览；如果应用支持三击选行，第三击松开后会更新预览。
- 浮窗优先显示在选区上方，上方空间不足时优先放到下方。长选区只显示开头。
- 浮窗不会自动超时；松开 `Ctrl` 就会收起。再次点击、滚动、切换窗口、按 `Esc` 或按其他非修饰键也可收起。
- 右键托盘图标可暂停、恢复或退出。暂停会停止监听。程序不会设置开机自启。

## 可选：离线词典

在项目目录运行 `.\Setup-Dictionary.ps1` 安装缺少的词库。普通构建和程序运行都不会下载词库。需要重新安装时使用 `-Force`；某个方向安装失败不会覆盖该方向已有的词库。

| 方向 | 数据来源 | 一次性下载 | 本地数据库 |
| --- | --- | --- | --- |
| 英汉 | [ECDICT](ECDICT-NOTICE.md)，校验固定版本的 SHA-256 | 约 66 MB | `dictionary-v1.sqlite`，约 20 MiB |
| 汉英 | [CC-CEDICT](CC-CEDICT-NOTICE.md)，验证数据格式并记录来源和 SHA-256 | 约 4 MB | `dictionary-zh-v1.sqlite`，约 10 MiB |

词库存放在 `%LOCALAPPDATA%\SelectionPreview`，应用改名后目录不变。

试着按住 `Ctrl` 选中 `week`、`电脑`、`電腦` 或 `画蛇添足`。浮窗先显示原文，查到后在下方补上最多两条释义。常见外层标点不影响查词。英文只查单词（不区分大小写）；中文支持 1–32 个连续汉字的整词匹配，支持简体和繁体，不会自动分词。中英混排、网址、未收录的词或词库不可用时，只显示原文。不翻译句子，也不保存生词或查词记录。

## 兼容性与隐私

程序只通过 Windows UI Automation 读取选区。应用允许选中文字，不代表它也会通过 UI Automation 提供选区。选区无法读取、缺少可靠的定位信息、读取超时、处于安全桌面或权限不足时，不会弹窗。程序会跳过系统标记的密码控件，不读写剪贴板、不模拟按键、不保存或上传选区。浮窗是普通桌面窗口，可能出现在录屏或屏幕共享中。

## 手动验证

1. 在记事本和 Edge 网页正文或输入框中测试拖选、双击、键盘扩选和 `Ctrl+A`。原选区和剪贴板应保持不变；浮窗不应阻挡鼠标。在记事本的行尾空白处双击，没有选中文字时不应弹窗；三击实际选中整行时应显示该行。
2. 不按 `Ctrl` 划词不应弹窗。按住 `Ctrl` 划词后保持至少 10 秒，浮窗应持续显示，松键立即收起。再测试普通单击、空选区、测试用密码框、滚动、切窗和托盘暂停。
3. 在缩放比例不同的双屏上测试上下边缘的选区，确认浮窗不会超出目标屏幕。在 125%、150% 或 200% 缩放下，`week` 等短词应完整显示，长段落应在浮窗尺寸上限内换行或截断。
4. 安装词库后断网，测试 `week`、`WEEK.`、`电脑`、`電腦`、`「星期。」` 和 `画蛇添足`。快速切换选区不应显示上一词的释义；松开 `Ctrl` 或切窗后，迟到的查词结果不应让浮窗重新出现。未收录的中文句子、中英混排和网址应只显示原文。
